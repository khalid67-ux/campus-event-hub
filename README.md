# Campus Hub

Campus Hub is a responsive web-based campus event management system that helps university students discover upcoming events, view event details, and register for campus events.

## Features

- Browse upcoming campus events
- Search events
- Filter events by category
- View complete event details
- Register for events
- Form validation
- Registration success message
- Save registrations using LocalStorage
- View registered events
- Download registration confirmation as PDF
- Cancel event registration
- Registration limit for events
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- jsPDF

## Purpose

The main goal of Campus Hub is to provide a simple and convenient platform for students to discover campus events and manage their registrations.
